Kizuato PC-98 English Patch

Project overview · 10 November 2026

Goal

Create an English translation patch for Leaf’s original PC-98 Kizuato while preserving its original graphics, FM music, effects, choices, timing, and gameplay. The intended release is a patch or reproducible transformation for someone who owns the game, not a complete game image.

What has been done

  • Inspected the supplied game files. Identified Kizuato’s packed scene archive and verified that extracting and rebuilding it without changes reproduces the original bytes.
  • Built tools to extract Japanese messages with stable IDs, keep story commands separate from translation, call a local PLaMo model, cache results, check text and branch structure, and insert drafts into a copy of the game.
  • Completed a first local draft pass for all 3,306 translatable messages. A disposable beta image contains 3,154 English drafts; the remaining messages stay Japanese when the current encoding or layout checks cannot safely fit them.
  • Prepared and started a second pass with verified cross-scene context, selected-choice history, a glossary, and stage-gated PC-98 character and clue notes. It runs locally and can be watched, stopped, and resumed without discarding completed work.

Current limits and next steps

The English is still draft text. Choice layout, page continuation, effects, and branch behavior need emulator checks before the patch can be called working. Some bonus-scene context remains uncertain, and the original text renderer may need further work to fit every English passage without cutting words.

After the second pass, review translation accuracy and character voice, resolve conflicting drafts, rebuild a fresh test copy, and test the opening choice and later routes in a PC-98 emulator. No original game image is modified, and no game assets or model weights are committed to the project repository.
